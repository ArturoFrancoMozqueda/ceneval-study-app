# Archivo histórico

**Nada de esta carpeta describe el producto actual. No la uses como referencia
para escribir código ni contenido.**

Se conserva porque es historia del proyecto y explica por qué se tomaron
algunas decisiones. Para el estado vigente, ve a
[`docs/PROJECT_STATUS.md`](../PROJECT_STATUS.md) y a
[`docs/auditoria-2026-08/`](../auditoria-2026-08/README.md).

| Archivo | Qué era | Por qué se archivó |
| --- | --- | --- |
| `01-product-vision-preeditorial.md` | Visión previa al giro editorial | Describe a la estudiante pegando su propia transcripción para que la app la procese. Ese modelo se abandonó: hoy el contenido se prepara antes de publicarse. Estaba en `app/docs/`, dentro del árbol de rutas. |
| `02-functional-requirements-preeditorial.md` | Requisitos de esa misma versión | Igual que el anterior. Copia vieja, divergente de `docs/02-functional-requirements.md`. |
| `03-user-stories-preeditorial.md` | Historias de esa misma versión | Igual que el anterior. La versión viva es `docs/03-user-stories.md`, bastante más extensa. |
| `CODEX_START_HERE.md` | Punto de entrada para agentes, de julio de 2026 | Instruía a no avanzar a navegación y pantallas hasta aprobar las historias. Navegación, pantallas, base de datos, exámenes y 40 clases ya existen. El punto de entrada ahora es `AGENTS.md`. |
| `07-roadmap.md` | Roadmap inicial | Su "próxima acción" era definir la personalidad visual y comenzar la entrega 1A, terminadas el 23 de julio de 2026. El plan vigente está en la sección 8 de `PROJECT_STATUS.md`. |

Archivados el 20 de agosto de 2026, a partir de los hallazgos de
[`docs/auditoria-2026-08/`](../auditoria-2026-08/README.md).
