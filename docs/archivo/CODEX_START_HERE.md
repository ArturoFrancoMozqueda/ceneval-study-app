# Prompt de inicio para Codex

Lee primero:

1. `AGENTS.md`
2. `docs/README.md`
3. `docs/PROJECT_STATUS.md`
4. `docs/03-user-stories.md`

Después inspecciona el repositorio real.

No asumas que los documentos ya fueron copiados correctamente ni que el código coincide con ellos.

Tu tarea inmediata es:

1. Mostrar qué archivos existen dentro de `docs`.
2. Confirmar si `docs/03-user-stories.md` existe.
3. Comparar su contenido con las historias requeridas.
4. Señalar qué falta o qué está duplicado.
5. Proponer una fusión segura.
6. No modificar todavía código funcional.
7. No avanzar a navegación y pantallas hasta que el usuario apruebe las historias.

Recuerda que el usuario no tiene experiencia técnica. Explica cada acción desde cero, da un paso a la vez e indica el resultado esperado.
