# Skills a nivel de repositorio

## `edu-agent-skills-*`

Diez skills copiadas de [`GarethManning/education-agent-skills`](https://github.com/GarethManning/education-agent-skills)
(commit vigente al 24 de agosto de 2026), seleccionadas por aplicar directo a
funciones ya existentes de Sube Legal:

| Skill | Función de Sube Legal a la que ayuda |
| --- | --- |
| `edu-agent-skills-retrieval-practice-generator` | Mini exámenes y flashcards |
| `edu-agent-skills-spaced-practice-scheduler` | Cola de repaso espaciado |
| `edu-agent-skills-individual-spacing-algorithm-explainer` | Personalizar el repaso espaciado por estudiante |
| `edu-agent-skills-assessment-validity-checker` | Auditar las preguntas de examen ya publicadas |
| `edu-agent-skills-criterion-referenced-rubric-generator` | Formalizar la progresión por niveles (decisión D-2) |
| `edu-agent-skills-learning-progression-builder` | Formalizar la progresión por niveles (decisión D-2) |
| `edu-agent-skills-gap-analysis-from-student-work` | Detección de temas débiles / qué repasar después |
| `edu-agent-skills-cognitive-load-analyser` | Revisar que las explicaciones de cada tema no saturen |
| `edu-agent-skills-formative-assessment-loop-designer` | Diseño del flujo de mini exámenes |
| `edu-agent-skills-learning-analytics-interpretation-guide` | Interpretar el progreso/resultados de la estudiante |

No se copiaron las otras 155 skills del repositorio (cubren dominios que no
aplican aquí: EAL, Montessori, pensamiento histórico, aprendizaje ambiental,
etc.). Si hace falta otra, está el catálogo completo en el repositorio
original.

### Licencia y uso permitido

El repositorio original usa **CC BY-SA 4.0** (permite uso comercial, exige
atribución y que cualquier adaptación se comparta bajo la misma licencia).

**Uso previsto — seguro:** herramienta interna de revisión y control de
calidad del contenido editorial ya producido (auditar exámenes existentes,
revisar carga cognitiva de una explicación, verificar la cola de repaso).

**Uso NO decidido todavía:** generar directamente con estas skills el texto
final que se publica y se vende (flashcards, preguntas de examen, etc.). La
cláusula ShareAlike puede complicar eso para un producto de pago cerrado —
no se activa ese uso sin decisión explícita de la titular del proyecto,
igual que el resto de las decisiones de Fase 0 en `docs/PROJECT_STATUS.md`.
